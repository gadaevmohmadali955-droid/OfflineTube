# TubeSync — Android Приложение

Приложение для сохранения каналов, видео и оффлайн-просмотра с поддержкой шеринга конфигами через уникальные ссылки.

---

## 📱 Как собрать и скачать APK на телефон через GitHub:

1. **Экспорт или отправка в GitHub:**
   - В правом верхнем углу интерфейса AI Studio нажмите на меню (три точки или шестеренка) -> **«Push to GitHub»** или **«Export»**.
   - Если вы создаете новый репозиторий, убедитесь, что вы авторизованы в GitHub.
   - **Важно:** Если репозиторий только что создан или приватный, страница может показывать 404 (Not Found), пока вы не войдете в свой аккаунт GitHub или пока первый коммит не будет отправлен.

2. **Автоматическая сборка в GitHub Actions:**
   - Как только код отправлен в GitHub, откройте в репозитории вкладку **«Actions»** (вверху страницы).
   - Там автоматически запустится задача **«Build TubeSync Android APK»**.
   - Вы также можете в любой момент запустить сборку вручную: нажмите **Actions** -> **Build TubeSync Android APK** -> кнопку **«Run workflow»**.

3. **Скачивание APK на телефон:**
   - Когда сборка завершится (появится зеленая галочка ✔):
     - Нажмите на завершенную сборку.
     - Прокрутите страницу вниз до раздела **Artifacts** (Артефакты).
     - Нажмите на **TubeSync-APK** — скачается zip-архив с готовым `app-debug.apk`.
     - Также готовый APK автоматически прикрепляется во вкладку **«Releases»** (Релизы) на главной странице репозитория справа.

4. **Установка на Android телефон:**
   - Откройте скачанный `.apk` файл на вашем телефоне.
   - Если Android покажет предупреждение безопасности:
     - Нажмите **«Настройки»** -> разрешите установку для браузера/проводника («Разрешить установку из этого источника»).
   - Нажмите **«Установить»** и готово!
